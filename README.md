## 📌 Sobre o Projeto

Portfólio pessoal e profissional desenvolvido com **HTML5 semântico, CSS3 moderno e JavaScript puro (Vanilla JS)**, sem frameworks pesados, garantindo carregamento instantâneo, alta performance e experiência visual fluida.

O site foi construído para apresentar minha trajetória, competências técnicas, certificações e os principais projetos reais desenvolvidos para clientes e comunidade.

🔗 **Acesse online:** [https://wagnerpessoa.me](https://wagnerpessoa.me) ou [https://wagnerpessoadev.github.io](https://wagnerpessoadev.github.io)

## ✨ Funcionalidades e Diferenciais

- 🎨 **Tema Dark/Light:** Alternância dinâmica de tema (claro/escuro) com persistência automática no `localStorage`.
- 💻 **Background Animado em Canvas:** Efeito typewriter no fundo da tela simulando código em digitação com realce sintático adaptativo ao tema.
- 🎴 **Efeito 3D Tilt:** Efeito tridimensional interativo nos cards de projetos ao passar o mouse via Vanilla JS.
- 🔍 **Modal Interativo de Projetos:** Janela modal detalhada com suporte nativo a vídeos demonstrativos em loop e imagens em alta definição, metadados (ano, função, categoria) e botão direto de acesso ao projeto.
- ✍️ **Typewriter Dinâmico:** Efeito de digitação no cabeçalho destacando as especialidades do desenvolvedor.
- 📱 **100% Responsivo & Mobile First:** Menu hambúrguer otimizado, gestos de revelação do cabeçalho em telas pequenas e layouts adaptáveis.
- 📩 **Formulário de Contato Integrado:** Validação de campos no front-end, feedback visual em tempo real e redirecionamento formatado para `mailto:`.
- ⚡ **Otimização de Performance:** Google Fonts assíncronas, imagens com `loading="lazy"`, isolamento de repaints com `contain` CSS e navegação suave via `scroll-padding-top`.

## 💻 Como Executar Localmente

Como o projeto é construído exclusivamente com tecnologias web padrão, não requer instalação de dependências ou processo de build:

### Opção 1: Via Python (Recomendado)
```bash
# Na raiz do projeto:
python -m http.server 8080
```
Acesse no seu navegador: `http://localhost:8080`

### Opção 2: Via Node.js
```bash
npx serve .
```

### Opção 3: Extensão Live Server (VS Code)
1. Abra a pasta do projeto no VS Code.
2. Clique com o botão direito no arquivo `index.html`.
3. Selecione **"Open with Live Server"**.

---

## 🌍 Deploy no GitHub Pages

Este repositório está configurado para publicação contínua via **GitHub Pages**:

1. Submeta as alterações para a branch `main`:
   ```bash
   git add .
   git commit -m "feat: atualizações do portfólio"
   git push origin main
   ```
2. No repositório do GitHub, acesse **Settings > Pages**.
3. Em **Branch**, selecione `main` e a pasta `/ (root)`.
4. O arquivo `CNAME` aponta automaticamente o domínio customizado para `wagnerpessoa.me`.
