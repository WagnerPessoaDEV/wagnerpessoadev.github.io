# 🌐 Wagner Pessoa | Portfolio

Portfólio pessoal bilíngue (PT/EN) desenvolvido com **HTML, CSS e JavaScript puro**, com foco em **performance**, **responsividade** e **experiência do usuário**.

Este projeto foi criado para apresentar minha trajetória profissional, minhas habilidades, projetos recentes, serviços e canais de contato de forma moderna, objetiva e acessível.

## 🚀 Demonstração

- **Portfólio online:** [wagnerpessoa.me](https://wagnerpessoa.me)
- **LinkedIn:** [linkedin.com/in/WagnerPessoaDev](https://www.linkedin.com/in/WagnerPessoaDev)
- **GitHub:** [github.com/WagnerPessoaDev](https://github.com/WagnerPessoaDev)

---

## 📌 Sobre o projeto

Este repositório contém um site estático de apresentação profissional, desenvolvido para destacar meu perfil na área de tecnologia.

### Principais características:
- Site bilíngue em **Português** e **Inglês**
- Interface moderna e responsiva
- Tema **claro/escuro** com persistência em `localStorage`
- Animações visuais para melhorar a experiência do usuário
- Modal com detalhes de projetos
- Estrutura leve e otimizada para deploy estático

---

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **Font Awesome**
- **Google Fonts**

---

## 📂 Estrutura do projeto

```txt
.
├── index.html                  # Página principal em português
├── index_en.html               # Página principal em inglês
├── style.css                   # Estilos globais
├── script.js                   # Interações principais do site
├── smooth-scroll.js            # Scroll suave customizado
├── background-animation.js     # Animação visual no background
├── OTIMIZACOES.md              # Histórico de melhorias de performance
├── CNAME                       # Configuração de domínio customizado
├── assets/                     # Arquivos estáticos
└── imagens/                    # Imagens utilizadas no site
```
---
## ✨ Funcionalidades
Menu responsivo
Alternância de idioma
Alternância entre tema claro e escuro
Efeito de digitação no destaque principal
Animações de entrada dos elementos
Modal para exibição de detalhes dos projetos
Layout adaptado para desktop e dispositivos móveis
Links diretos para contato profissional

---

## 💻 Como executar localmente

Como este é um projeto estático, você pode executá-lo de forma simples:

Opção 1

Abra o arquivo index.html diretamente no navegador.

Opção 2

Utilize um servidor local, como o Live Server no VS Code:

Abra a pasta do projeto no VS Code
Execute a extensão Live Server
Acesse a URL local gerada no navegador

---

## 🌍 Deploy

Este projeto está preparado para deploy estático, especialmente no GitHub Pages.

Passos básicos
Publique o repositório no GitHub
Ative o GitHub Pages nas configurações do repositório
Verifique se o arquivo CNAME está configurado corretamente para o domínio personalizado

---
